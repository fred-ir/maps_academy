    Schematic Creation

    Now that the CSA core is designed with real transistors, test its behavior in the CSA configuration.

    For this step, reuse the schematic of step3_idealCSA_Rf.

    In the Library Manager, locate:

    On the schematic view, select Copy

    A Copy View window will appear. On the right side, enter:

    Run Simulation

    Create the ADE Explorer test bench. When the ADE Explorer window opens, import the test bench settings from a previous run:

    Session->Import

    In the Select View section, choose:

    Library Cell View
    MAPS_academy_lab step3_idealCSA_Rf maestro

    Click OK.

    This imports all the analyses, outputs, and expressions configured previously.

    Run the simulation and wait for completion.

    Extra Simulations

    The goal of the next steps is to perform ToA (Time of Arrival) and ToT (Time Over Threshold) measurements.

    In Maestro, add outputs by clicking on the Add Expression button . This adds a new line in the Outputs Setup pane. Ensure the type is set to expr.

    In the Details field, add the following expression for ToA: 

    (cross(VT("/out") 1.02 1 "rising" nil nil nil) - 1e-07)
    Set the Name to toa.

    Repeat the operation for toe (Time of End) with the expression: 

    (cross(VT("/out") 1.02 1 "falling" nil nil nil) - 1e-07)

    For the next expression, use toe-toa and name it tot.

    Now, run a simulation with Qin ranging from 100 to 2000 electrons, with a step of 100 electrons.

    The results should look like the following:

    You can update the threshold by changing the value 1.02 to 1.01 in the toa and toe expressions. The plot can be re-evaluated without re-running the simulation by clicking the Plot Outputs button .

    You can also explore lower values by setting Qin from 50 to 500 with a step of 20 electrons.
