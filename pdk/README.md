# SKY130 PDK installation

## Requirements

- `tcsh` shell

## Installation
To install the PDK, just run `install.sh` script

```
./install.sh
```

## Clean installation
To clean the installation and remove the PDK, just run `clean.sh` script

```
./clean.sh
```
