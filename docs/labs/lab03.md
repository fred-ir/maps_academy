# Ideal Charge Sensitive Amplifier (CSA)

## Schematic

In the `Library Manager` window create a new schematic:

| Library             | Cell              | View      |
|---------------------|-------------------|-----------|
| MAPS_academy_lab    | step2_tb_idealCSA | schematic |

While adding the `step1_idealOpAMP` symbol, in the `Add Instance` pop-up, press the `Upside Down` button to flip the symbol horizontally so the negative pin is on the top. Place the symbol back on the schematic.

![Schematic ideal CSA](../images/lab03_1.png)

In order to recreate the rest of the ideal CSA schematic as in the picture above we need to add two capacitors:

| Library    | Cell | View   |
|------------|------|--------|
| analogLib  | cap  | symbol |

A pulsed current source:

| Library    | Cell   | View   |
|------------|--------|--------|
| analogLib  | ipulse | symbol |

We also need the output pin `out` and the `gnd` symbol.

The value of the capacitances: input Cd = 10 fF, feedback Cf = 3 fF.

To change the values, select the capacitance by clicking on it with a ++left-button++.

!!! menu "Edit->Properties->Objects"
    ++q++

## Test bench

Now let’s create out maestro view for this test bench.

!!! menu "Launch-> ADE Explorer"

A pop-up window should appear. Select `Create New View`.

The next pop-up window will be filled-in automatically, so we can just press `OK`.

As before we can change between the schematic and the ADE Explorer by selecting the different tabs.

![maestro tab](../images/lab02_22.png)

Let’s add the Analysis to the test bench by clicking on the `Click to add analysis` on the `Setup` panel on the left side of the `Virtuoso ADE Explorer`.

This time we will choose the `tran` analysis, which will give us the behavior of the circuit in time.

Select `Stop Time` to 20u (which is 20 µs) and press ++enter++.

We also need to add a design variable `Qin`, which is the input charge (in electrons) generated by the input current source.

In the Setup pane of the `ADE Explorer` click ++right-button++ on the `Design Variables` and choose `Copy From Cellview`. This will cause the `Qin` to appear in the `Design Variables` list.

Double click on the right side of the `Qin` to change its value to 1000.

Now, add the voltage that we will be observing.

!!! menu "Outputs->To be Plotted-> Select On Design"

Select the `out` pin.

## Simulation

Go back to `Virtuoso ADE Explorer` (`maestro` tab) and run the simulation.

!!! menu "Simulation->Netlist and Run"
    Or click the button from the tab on the right side.

    ![Run Simulation](../images/lab02_24.png)

    If the tab is closed by accident you can open it back by 
    
    !!! menu "Window->Toolbars->Run"

When the simulation is done you should see that the CSA is integrating, rising the voltage with each current pulse. This is done because there is no reset mechanism for the feedback resistor.

This ideal CSA can work with both polarities of the input charge.

Change the `Qin` parameter in the `ADE Explorer` from 1000 to -1000 and restart the simulation to see the effect.
